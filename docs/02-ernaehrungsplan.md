# Ernährungsplan – Meier G.

**Ziel: ~3'750 kcal/Tag** in **6 kleinen Mahlzeiten** (nicht 3 grossen –
das ist bei niedrigem Appetit der entscheidende Trick: kleine Portionen
schafft der Kopf, grosse Teller schrecken ab).

## Tagesplan

| Zeit | Mahlzeit | kcal |
|---|---|---|
| 07:15 | Power Oats | 750 |
| 09:30 | Snack (Banane / Nüsse) | 300 |
| 12:15 | Reisbowl (Hähnchen) | 900 |
| 16:00 | Quark-Bowl / Wrap / Toast | 550 |
| 18:30 | Hackfleisch-Pasta o. Ä. | 850 |
| 22:00 | Gainer-Shake | 400 |
| | **Total** | **~3'750** |

## Kernprinzipien

1. **6 kleine statt 3 grosse Mahlzeiten** – wegen niedrigem Appetit.
2. **Flüssige Kalorien als Fallback** an appetitlosen Tagen: der Gainer-Shake
   geht immer, auch wenn nichts «reingeht».
3. **Grosszügig Öl/Fett** – Kaloriendichte ohne viel Magenvolumen (Olivenöl über
   die Bowl, Erdnussbutter, Nüsse, Vollfett-Milchprodukte).
4. **Meal Prep am Sonntag (~60 Min)** deckt Mo–Do ab → unter der Woche keine
   Ausreden, das Essen steht bereit.

## Gainer-Shake (der Fallback)

Milch + Oats + Banane + Erdnussbutter + Honig, mixen. ~400 kcal, geht auch bei
null Appetit runter. An richtig schlechten Tagen kann er eine feste Mahlzeit
ersetzen, statt dass gar nichts gegessen wird.

## An 21:00-Slot-Tagen (Mo / Mi / Fr)

Der späte Slot verschiebt den Abend – deshalb die letzten Mahlzeiten vorziehen:

- **Abendessen auf 18:00 vorziehen** (statt 18:30)
- **Shake um 20:15** (vor dem Slot, nicht danach)
- **Letzte Mahlzeit 22:15** nach dem Slot – leicht, damit der Schlaf nicht leidet

## Anpassungsregeln

Siehe [`04-fortschritt-kontrolle.md`](04-fortschritt-kontrolle.md) für die
vollständige Logik. Kurzfassung:

- **Kein Zuwachs nach 2 Wochen** → einen zusätzlichen Shake pro Tag einbauen
- **Über +0.7 kg/Woche** → letzte Mahlzeit halbieren (Zunahme soll Muskel sein,
  nicht nur Fett)
